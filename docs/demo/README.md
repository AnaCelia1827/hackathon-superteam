# English demo video

`looprail-demo-en.mp4` presents the problem, deterministic 50-step replay,
simulated metrics, recorded Surfpool sandbox settlement, and proposed business
model. The replay and the on-chain sandbox payment are separate runs.

To record again on Windows, start `apps/dashboard/server.py` at port 8000, then run
`record_demo.py` from the repository root using a Python environment with
Playwright and imageio-ffmpeg. The script uses installed Chrome and the Windows
Microsoft Zira English voice. Edit `narration.json` to change the script.
